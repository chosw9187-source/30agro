# 인사평가 전체 점검 (2026-10-13)

지금 굴러가는 한 해의 사이클을 처음부터 끝까지 따라가며 적은 점검표입니다.
**A. 지금 돌아가는 사이클** → **B. 결정이 필요한 것(제가 물었던 것 포함)** →
**C. 추천 기능** → **D. 인사팀이 직접 할 데이터 정리** 순서입니다.

---

## A. 지금 돌아가는 사이클 — 한 해의 흐름

| #   | 단계           | 누가              | 하는 일                                                                                                                             | 잠금                                                                        |
| --- | -------------- | ----------------- | ----------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| 0   | 연도 만들기    | 인사팀            | 연도를 넣으면 **목표설정 · 성과평가(중간) · 성과평가(최종) · 역량평가** 네 단계가 한 번에 생김                                      | —                                                                           |
| 1   | 목표설정       | 전원              | 전사 → 부문(책임) → 팀 → 개인목표 등록. 가중치 합 100% 검사                                                                         | **목표 확정**을 찍으면 내용(제목·지표·가중치·담당)이 잠기고 달성률만 올라감 |
| 2   | 성과평가(중간) | 본인 → 1차 평가자 | 본인이 달성률·자기점수, 1차 평가자가 점수·코멘트, 「평가완료」                                                                      | 사이클을 닫으면 달성률까지 읽기 전용                                        |
| 3   | 성과평가(최종) | 본인 → 1차 평가자 | **같은 목표 한 벌을 이어받아**(목표를 복사하지 않음) 최종 점수                                                                      | 〃                                                                          |
| 4   | 역량평가       | 본인 → 1차 평가자 | 1~10점 문항(핵심가치 · 직무역량) + **전체 코멘트 필수**                                                                             | 「역량평가 마감」을 찍으면 입력 불가                                        |
| 5   | 등급 매기기    | 인사팀 · 운영책임 | 라인별 **조직등급** → **정원표(배분율)** → 점수 순위로 개인등급 자동 → 경계·동점은 인사팀이 확정 → 운영책임 **가산점(± 점 + 사유)** | —                                                                           |
| 6   | 결과 배포      | 인사팀            | **네 단계가 모두 마감돼야** 배포 가능. 배포해야 직원에게 등급이 보이고, 그 등급이 **인사카드 이력**에 적힘                          | —                                                                           |
| 7   | 합의 / 이의    | 본인 → 인사팀     | 「최종등급 확인」 칸에서 **합의** 또는 **이의 제기**(사유 필수) → 인사팀 답변                                                       | 답변이 달리면 본인은 못 고침                                                |
| 8   | 마감           | 인사팀            | 그 해를 닫음(진행 띠의 「종료」)                                                                                                    | —                                                                           |

보조 장치: 중도입사자 자동 제외(**입사 기준일**) · 사람별 포함/제외(평가대상자 관리) ·
시점 동결(체크포인트) · 엑셀 내려받기(15칸) · HR REPORT(점수·등급·확인 상태).
목표 「합의」 단계는 꺼져 있고(요청대로) 진행 띠에서도 뺐습니다.

## B. 결정이 필요한 것

### B-1. 제가 물었는데 아직 답을 못 받은 것

| 번호 | 물음                                                                             | 지금 상태                                                                                        | 제 추천                                                       |
| ---- | -------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ | ------------------------------------------------------------- |
| Q1   | 이의 접수·답변 **알림**을 보낼까요?                                              | 인사평가 모듈은 **알림을 하나도 쓰지 않습니다** — 인사팀이 화면을 열어야 이의가 들어온 걸 압니다 | **넣기**(C-1에 묶음)                                          |
| Q2   | 합의/이의 **선택 기한**을 띄울까요?                                              | 기한 없음. 안 고르면 영원히 「미확인」                                                           | 배포 후 7일(날짜는 인사팀이 입력)                             |
| Q3   | 이의를 **팀장에게 공유**할까요?                                                  | 인사팀만 봅니다. 팀장은 못 봅니다                                                                | 지금처럼 비공개 + 인사팀이 필요할 때만 「팀장에게 소명 요청」 |
| Q4   | 진행 띠 마지막 「합의」 마디를 배포 뒤 **「합의 N명 / 이의 N건」**으로 보일까요? | 지금은 켜짐/꺼짐만                                                                               | 숫자 표시(인사팀에게만)                                       |
| Q5   | 기중 **소속·직책 변경**(인사팀장 → 10/1부로 구매팀장, 80/20 가중)                | 평가 사슬은 **오늘자 조직도만** 봅니다                                                           | B-2의 F6 참조                                                 |
| Q6   | 미리보기 **E-1·E-2·E-3·E-5·E-6** 중 진행할 것                                    | 그림만 있음                                                                                      | E-5(결과지 인쇄·PDF)를 먼저                                   |
| Q7   | 용어 「합의 / 이의」 vs 「동의 / 이의신청」                                      | 답이 없어 **「합의 / 이의」로 맞춰 배포**했습니다                                                | 그대로 두기(바꾸려면 10분)                                    |

### B-2. 제가 코드를 훑어보고 찾은 것 — 결정이 필요합니다

| 번호    | 무엇이                                                | 왜 문제인가                                                                                                                                                         | 선택지                                                                                                                                                                        |
| ------- | ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **F1**  | **2차 평가자가 적는 칸이 없습니다**                   | 성과·역량 모두 「본인 → 1차 평가자」 두 칸뿐입니다. 2차 평가자는 화면·엑셀에 **이름만** 나옵니다. 실제로 2차가 개입하는 자리는 운영책임 **가산점**뿐입니다          | ① 지금처럼(2차 = 가산점·등급조정) ② 2차 평가자 **의견만** 적는 칸 ③ 2차 **점수**까지 받아 가중(예: 1차 70 / 2차 30)                                                           |
| **F2**  | **책임 · 운영책임 · 사장은 역량평가 대상이 아닙니다** | 역량 점수가 비면 종합점수·등급이 **안 나오고**, 배포해도 인사카드 이력에 남지 않습니다                                                                              | ① 성과 100%로 등급 ② 임원용 역량 양식 별도 ③ 「등급 비대상」으로 명문화하고 화면에도 그렇게 적기                                                                              |
| **F3**  | **배포가 미입력자를 막지 않습니다**                   | 단계 마감 여부만 봅니다. 점수가 빠진 사람은 조용히 등급 없이 지나가고 이력에도 안 남습니다                                                                          | 배포 전 **점검표**(미입력 N명 · 가중치 100% 아닌 사람 · 조직등급 없는 라인)를 띄우고 그래도 배포할지 묻기                                                                     |
| **F4**  | **알림이 없습니다**                                   | 자기평가 요청, 1차 평가 대기, 마감 임박, 결과 배포, 이의 접수·답변 — 전부 들어와 봐야 압니다                                                                        | C-1                                                                                                                                                                           |
| **F5**  | **휴직 개념이 없습니다**                              | 재직/퇴직만 있습니다. 육아휴직 6개월인 사람도 평가 모수와 정원에 그대로 들어갑니다                                                                                  | ① 휴직 기간을 적고 모수에서 빼기 ② 근무 개월수로 가중 ③ 사람별 제외로 손수 처리(지금)                                                                                         |
| **F6**  | **기중 소속·직책 변경**                               | 사슬·등급 라인은 **오늘자 조직도**로만 계산합니다. 1~9월 인사팀장 / 10~12월 구매팀장을 가를 수 없습니다. 다만 **발령 이력 표(날짜·부서·직책·직급)는 이미 있습니다** | ① 단계별 **스냅샷**(목표설정·중간·최종 시점의 소속을 얼림) ② 발령 이력으로 **기간 가중**(80/20) 자동 ③ 사람별로 인사팀이 손으로 비율 입력 — **추천: ①을 먼저, ②는 그다음 해** |
| **F7**  | **점수 변경 이력이 없습니다**                         | 누가 언제 점수를 고쳤는지 안 남습니다. 이의가 「점수가 바뀌었다」로 가면 근거를 댈 수 없습니다                                                                      | 점수 바뀔 때 한 줄씩 적는 변경 이력(인사팀만 조회)                                                                                                                            |
| **F8**  | **평가자 공석 · 장기 부재 대행이 없습니다**           | 팀장이 비면 조직도를 고치는 수밖에 없습니다                                                                                                                         | 그 해에만 쓰는 **평가자 대행 지정** 한 줄                                                                                                                                     |
| **F9**  | **조직 데이터 정합성**                                | 기준을 「사용자 관리 카드」로 바꾸면 26명 중 **9명**의 사슬이 달라졌습니다(팀장 근거 부재 · 카드에 남은 옛 소속 · 등급 라인 이동)                                   | 「조직 데이터 점검」 화면(어긋난 줄만 모아 보여 주기)                                                                                                                         |
| **F10** | **배포 취소 뒤 합의가 남습니다**                      | 배포를 되돌려 등급을 고치고 다시 배포하면, **예전 등급에 한 합의**가 새 등급에 대한 합의처럼 남습니다                                                               | 배포 취소 시 그 해 합의·이의를 **함께 초기화**(또는 「등급이 바뀌었습니다 — 다시 확인해 주세요」로 표시) — **추천: 후자**                                                     |

## D. 인사팀이 직접 할 데이터 정리

1. **재무경영관리 5팀**(인사 · 재경 · 경영기획 · 경영지원 · 구매)과 **사업개발팀**의 팀 관리 「본부」 칸 **비우기** — 본부 개념이 없는 라인입니다.
2. 사람 카드에 남아 있는 **옛 소속**(팀을 옮겼는데 카드의 본부·사업단위가 그대로인 사람) 정리.
3. **팀장이 비어 있는 팀** 확인 — 1차 평가자가 정해지지 않습니다.
4. 라인별 **조직등급**이 비어 있으면 그 라인은 등급이 매겨지지 않습니다 — 배포 전 확인.
