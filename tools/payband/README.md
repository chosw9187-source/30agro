# Pay-band 시뮬레이터 (단독 HTML)

- `payband.html` : 엑셀 「직급_PayBand_분류_업로드용」 산식을 그대로 옮긴 정적 페이지 (claude.ai Artifact로 배포)
  - `#payband` : 기본정보 · 분류 · 생애연봉 시뮬레이션 · 시뮬레이션 상세 (엑셀 시트 재현)
  - `#analysis` : 임금분석 — 개인별 Pay-band 위치, 인상률 시뮬레이션, 상한 이탈 연도 경고, 정렬·필터, A안(일률)/B안(밴드 위치 차등) 비교
- 직원 데이터는 페이지에 넣지 않는다. 열람자가 「엑셀 불러오기」/「붙여넣기」로 넣으면 그 브라우저에만 저장된다.
- 산식 검증: 엑셀(LibreOffice 재계산) 계산 시트 O2·DK2 및 연도별 연봉과 원 단위 일치 (2026.11.03).

## 배포용 ZIP (`dist/SG한국삼공_보상체계분석.zip`)

- 압축을 풀고 `SG한국삼공_보상체계분석_실행.bat`(또는 HTML)을 더블클릭하면 기본 브라우저로 열린다.
- SheetJS를 HTML 안에 넣어 인터넷 없이도 엑셀 업로드가 된다. 글꼴만 인터넷이 없으면 맑은 고딕으로 대체된다.
- 다시 만들기: `python3 tools/payband/build_zip.py <xlsx.full.min.js 경로>` (스크립트 상단 주석 참고)
