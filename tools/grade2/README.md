# SG한국삼공 직급 분류 (신규 기준)

기존 「보상 체계 분석」 사이트(`tools/payband`)와 별도로 운영하는 사이트. 기존 사이트의 Pay-band 분류 화면을 바탕으로, 1차 분류를 4개 기준 종합 방식으로 바꿨다.

## 구성

| 단계 | 탭 | 내용 |
|---|---|---|
| 분류 기준 | 1차 분류 기준 | (1) 현직급 변환 · (2) 연차 · (3) 직무 역할 · (5) 가중치 + (4) 신규 Pay-band · 정년 · 생애연봉 시뮬레이션 기준(④⑤⑥⑦⑧) |
| | 2차 분류 기준 | 2차 연 상승률 · 년차 수 · 2차 기준연봉표 |
| 1차 분류 | 기본정보 | 인원 입력 (직무 역할 · 인사평가 선택, 연차 자동) |
| | 1차 분류 (종합 등급) | 기준별 직급 → 종합 점수 · 등급 → 최종 확정(수기) · 특이사항 체크 · ▶ 생애연봉 |
| | 생애연봉 시뮬레이션 · 시뮬레이션 상세 | 기존 사이트와 같음. 적용 직급(최종 확정 > 종합 등급) 시나리오를 함께 표시 |
| 2차 분류 (최종) | 2차 분류 · 생애연봉 · 상세 | 기존 사이트와 같음. 1차 적용 직급 기준으로 년차 확정 |
| 보고용 | — | ① 기본 현황 ② 분류 결과(종합 등급 → 최종) · 특이인원 ③ 분류 기준(자동 연동) |

## 1차 분류 기준 (기본값, 분류 기준 단계에서 수정)

| 기준 | 내용 |
|---|---|
| (1) 현직급 변환 | G6 → G4 / G5·G4 → G3 / G3·G2 → G2 / G1 → G1 |
| (2) 연차 | 1~6년차 G1 / 7~12년차 G2 / 13~19년차 G3 / 20년차 이상 G4 |
| (3) 직무 역할 | 정형 업무 G1 / 자율·기획 업무 G2 / 과제 리딩 G3 / 전략적 판단 G4 |
| (4) 연봉 | 신규 Pay-band G1 4,000~5,500 / G2 4,700~6,700 / G3 5,600~8,100 / G4 6,700~9,900 (만원) |
| (5) 종합 | 가중 평균(기본 각 25%) → 반올림(.5 이상 올림) = 종합 등급 |

- 연차 = 현직급 기본연차 + 현직급 기간(년, 내림) + 조정(±년)
- 현직급 기본연차 초기값(G1 1 / G2·G3 7 / G4·G5 13 / G6 20)은 변경 직급의 시작 연차로 넣은 임시값이다. 실제 기준 확인이 필요하다.
- 연봉 중첩 구간은 중간값(예: G1·G2 = 1.5)으로 계산한다. 밴드 미달은 G1, 초과는 G4로 본다. 값이 없는 기준은 빼고 가중치를 다시 나눈다.
- 적용 직급 = 최종 확정(수기)이 있으면 그 값, 없으면 종합 등급. 생애연봉 · 2차 분류 · 보고용이 이 값을 쓴다.
