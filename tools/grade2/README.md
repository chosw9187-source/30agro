# SG한국삼공 직급 분류 (신규 기준)

기존 「보상 체계 분석」 사이트(`tools/payband`)와 별도로 운영하는 사이트. 기존 사이트의 Pay-band 분류 화면을 바탕으로, 1차 분류를 4개 기준 종합 방식으로 바꿨다.

## 구성

| 단계 | 탭 | 내용 |
|---|---|---|
| 분류 기준 | 1차 분류 기준 | (1) 현직급 변환 · (2) 년차 · (3) 직무 역할 · (5) 가중치 + (4) 신규 Pay-band · 정년 · 생애연봉 시뮬레이션 기준(④⑤⑥⑦⑧) |
| | 2차 분류 기준 | 2차 연 상승률 · 년차 수 · 2차 기준연봉표 |
| 1차 분류 | 기본정보 | 인원 입력 (직무 역할 · 인사평가 선택, 년차 자동) |
| | 1차 분류 (산출 직급) | 기준별 분류직급 → 참고사항(남은 정년) → 종합 점수 · 산출 직급 → 최종 확정(수기) · 특이사항 체크 (1차 생애연봉 탭 없음) |
| 1차 특이사항 보고 | — | (보고용) ① 기본 현황 ② 분류 결과 · 1차 특이인원(최종 직급 판단) ③ 1차 분류 기준(자동 연동) |
| 2차 분류 | 2차 분류 (직급 년차) · 생애연봉 · 상세 | 열 구분: 1차 결과(출처) / 년차 기준(변경 직급 · 차감 · 년차 · 체류) / 연봉 기준(참고) / 차이. 최종 년차 = 년차 기준 (총 년차 − 하위 직급 체류연수 G1 4 · G2 4 · G3 5), 수기 우선. Pay-band 위치 · 2차 특이사항 체크. 최종 직급·년차 칸은 전원 같은 색(특이사항 별도 표시 없음) |
| 2차 특이사항 보고 | — | (보고용) ① 2차 년차 결정 · 기준연봉 차이 · 점검 대상 ② 2차 특이인원(최종 년차 판단) ③ 2차 분류 기준(자동 연동) |
| 최종 직급 | — | 이전 직급 → 최종 직급 · 년차, Pay-band 위치 |

## 1차 분류 기준 (기본값, 분류 기준 단계에서 수정)

| 기준 | 내용 |
|---|---|
| (1) 현직급 변환 | G6 → G4 / G5·G4 → G3 / G3·G2 → G2 / G1 → G1 (고정 변환) |
| (2) 년차 | 0~6년차 G1 / 7~12년차 G2 / 13~19년차 G3 / 20년차 이상 G4 |
| (3) 직무 역할 | 현직급별 직무 역할 직급을 전원 일괄 적용 (기본 G6 → G4 / G5·G4 → G3 / G3·G2 → G2 / G1 → G1). 개인 직무 역할을 고르면 개인 값 우선. 역할 정의: 정형 업무 G1 / 자율·기획 업무 G2 / 과제 리딩 G3 / 전략적 판단 G4 |
| (4) 연봉 | 현 연봉이 들어가는 신규 Pay-band 직급 (G1 4,000~5,500 / G2 4,700~6,700 / G3 5,600~8,100 / G4 6,700~9,900 만원). 밴드가 겹치는 금액은 (1) 변경 직급 밴드 우선, 하한 미만 G1 · 상한 초과 G4. 현 연봉이 변경 직급 밴드 밖이거나 최종 확정(수기) 직급 밴드 밖이면 빨간 테두리 |
| (5) 종합 | 가중 평균 종합 점수(1.00~4.00) → 점수 구간으로 종합 등급 (기본 G1 1.00~1.50 미만 / G2 1.50~2.50 미만 / G3 2.50~3.50 미만 / G4 3.50~4.00, 시작 점수 수정 가능) |

- 년차 = 기준일(2027-01-01, 오늘 날짜와 무관) 연도 − 입사 연도 + 경력인정(년) + 조정(±년). 예: 26년 입사 = 1년차, 23년 입사 = 4년차 + 경력인정 + 조정. 신입은 경력인정 없음, 소수는 올림, 최소 0년차, 수기 년차 입력 시 그 값 우선.
- 값이 없는 기준은 빼고 가중치를 다시 나눈다.
- 적용 직급 = 최종 확정(수기)이 있으면 그 값, 없으면 종합 등급. 생애연봉 · 2차 분류 · 보고용이 이 값을 쓴다.

## 진급 기준 · 진급 시 연봉 인상

1차 생애연봉 · 2차 생애연봉 화면 맨 아래와 분류 기준 › 2차 분류 기준에 같은 표가 있다 (어디서 고쳐도 같은 값).

| 항목 | 내용 (기본값) |
|---|---|
| 승진 대상 (2차) | 직급 근속 년차(승진한 해 = 1년차)가 G1 4 · G2 4 · G3 5년차 이상이면 27년부터 대상 → ⑧ 누락 횟수만큼 탈락 후 승진. 예: G1 1·2·3 → 4년차 누락 → 5년차 G2 승진 → 6·7 → 8~11년차 누락 → 12년차 G3 승진 → 13·14·15 → 16~20년차 누락 → 21년차 G4 승진 |
| ⑧ 승진 단계별 진급누락 | 전 인원 동일 (인사평가 무관): G1→G2 1회 · G2→G3 4회 · G3→G4 5회 × 누락 1회당 지연 1년, 분류 기준 › 1차 분류 기준 ⑧에서 수정 |
| 2차 연봉 | 매년 = 전년 × (1+2.5%) · 승진 연도 = 전년 × (1+2.5%) + 승진 정액(④ 350 · 400 · 350만원), 다음 해부터 그 금액 × (1+2.5%) · 직급 상한(CAP) 동결 |

## 나이 기준

- 나이 = 2026 − 출생연도 (생일 경과와 무관). 26년 = 그 나이, 27년 = +1세. 정년 연도 = 2026 + (정년 − 나이). 예: 1989-08-10생 → 26년 37세 · 27년 38세 · 44년 55세(정년)
- 2차 분류 표 「정년 최종연봉」 = 최종 직급 · 최종 년차(2차 분류 결과)로 2차 생애연봉 계산, 그 해 직급 Pay-band 상한(CAP, G4 9,900만원 등)에서 동결 · 이미 상한 이상이면 현 연봉 유지
